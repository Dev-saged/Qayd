## الإضافات
- **التقارير** (من "المزيد"): مبيعات آخر 7 أيام برسم بياني، وأرقام الشهر (المبيعات، التحصيل، الديون الجديدة، المصروفات، الدخل النقدي، الصافي)، ودخل الشاشات، وفواتير الكهرباء، وأكبر المدينين، وأداء كل عضو في الفريق.
- **قفل التطبيق بالبصمة** أو الوجه أو رمز قفل الجوال. يُفعّل من "المزيد"، ويقفل عند الفتح وبعد دقيقة غياب.
- **نسخة احتياطية** (لصاحب المحل): ملف بكل الزبائن والحركات والمصروفات الثابتة والقراءات والقوالب، يُحفظ أو يُرسل.
- **التحديث الذاتي:** يظهر شريط "تحديث جديد" عند صدور بناء أحدث، فينزّله ويفتح التثبيت مباشرة دون الدخول إلى GitHub.

## المميزات
- كل بناء على main يُنشر Release ويصل للتطبيقات المثبتة تلقائياً.
- اختبار شامل: 31 فحصاً حياً للخادم (الصلاحيات، العزل، المميزات، إيقاف الموظف، الحذف، الأسعار)، واختبارات حسابات الأرصدة والكهرباء والقوالب والتقارير، ولقطات لكل الشاشات.
